# Welcome to UglyDudeLabs! 👋

## I'm Corwin. I'm in IT, I'm doing my degree in Computer Science and I have the habit of always finding something new that I want to learn about before I finish my last project.

That's pretty much why UglyDudeLabs exists.

I've spent many years working with various computer systems and in recent times have become more interested in actually understanding how they work rather than just knowing how to use them.

Some projects will work on the first go. Others are likely to end up as a lot bigger experiment than I originally envisaged. Either way I'm just chugging along.

## What I'm working on

* Learning Git and GitHub while going through and tidying up my old programming projects.
* Revisiting the C++ and Python projects from my CS coursework.
* Exploring PowerShell, automation and sysadmin in my personal lab.
* Getting better at documenting what I'm doing, including the mistakes.
* Coming up with a ridiculously large number of ideas for future projects.

## Technical background

`Windows` · `Red Hat Linux` · `Active Directory` · `VMware` · `VirtualBox` · `Cisco Networking` · `PowerShell`

The majority of my professional experience has been in the area of troubleshooting, maintaining and supporting IT systems. I'm currently in the process of extending that into programming and building my own tools.

## My approach

**Build something. Break something. Figure out why. Try again.**

I enjoy figuring things out, even when they're frustrating. Sometimes that means spending hours investigating something that probably has a much easier solution.

But I do enjoy understanding things at a fundamental level and I'm quite happy if an experiment turns out to be a dead end.

If I learned something along the way, it was worth doing.

Anyway, welcome to UglyDudeLabs. We'll see what happens!
